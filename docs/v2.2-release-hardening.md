## Correctness and preservation

Automated PDF.js extraction passes exact English, Korean, and mixed phrases. The actual OCR viewer repeats these phrases on all four rotated pages. Existing page 5 remains exact `EXISTING TEXT` without overlay duplication; unselected scanned page 6 has no added text. Page count/order are preserved.

The added representative preservation fixture reloads page size, CropBox, 90° rotation, title/author/subject/keywords/creator/producer, creation/modification dates, URI link, annotations, AcroForm text value, and a simple outline/bookmark. Every original raw content-stream byte sequence remains present in the output. This supports ordinary representative structures, not arbitrary implementation-specific PDFs.

Viewer canvas comparison is pixel-identical for pages 1 and 5. Other pages differ in 0.4214% of channels by at most one intensity level, consistent with PDF.js taking a different image resampling path after appended text. Dimensions match and original streams remain byte-identical. It is not a claim of byte-identical PDF files or absolutely identical rasterizations.

Signatures can be invalidated by modification. Encrypted/password-protected PDFs remain unsupported; dynamic forms, optional content, unusual outlines, and implementation-specific structures do not have blanket preservation guarantees. Serialization cannot be interrupted mid-save; cancellation/supersession guards reject its result afterward.

## Unpublished release-note inputs

- Major changes: canonical root-level namespace; strict TypeScript foundation with JS coexistence; local PDF → Text; searchable PDF output with English/Korean/mixed Unicode and selected-page OCR.
- Privacy: processing on the user's device; same-origin OCR/PDF/font assets; no cloud OCR. Runtime assets must load before use; blanket offline availability is not promised. The current AdGuard-injected audit is not a clean network release sign-off.
- Compatibility: all 17 old Web Utilities `/tools/*` routes permanently redirect to canonical destinations; existing tools remain available.
- Verified limitations: OCR depends on image quality; larger PDFs use more time/memory; line-box highlights are approximate; password-protected PDFs are unsupported; modifying signed/complex PDFs may affect signatures or implementation-specific structures. Download artifact verification and the remaining live regression gates must be resolved before release.
