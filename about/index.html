About

Small tools. Inspectable trust.

Secure Tools is a privacy-first collection of everyday file utilities built to run locally in the browser.

Why it exists

Common file tasks should not require uploading personal documents to an unknown server or creating an account.

Local-first and open

The project favors static, understandable code and a privacy model that anyone can verify through source and network inspection.
