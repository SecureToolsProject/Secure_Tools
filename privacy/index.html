Privacy model

Privacy is an architectural choice.

Secure Tools is designed to process file contents locally in your browser. This page describes the current technical model, not a promise about unfinished features.

Local file processing

Supported tools read and transform files in browser memory. File contents are not sent to a Secure Tools server.

No accounts or analytics

The web hub has no user accounts, analytics, behavioral tracking, advertising, or tracking pixels.

Preference storage

localStorage is used only to remember your language and theme selections on this device.

External links

Following an external link, such as GitHub, leaves Secure Tools and is governed by that service's own policies.
